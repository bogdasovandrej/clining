# Проверка обновлённой версии

Дата: 25.09.2026. [Публичная версия](https://storage.yandexcloud.net/clining-preview-bogdasovandrej-20260920/preview.html?v=20260925-design).

## 1. Сборка и данные

- `npm run build`, `npm run check`, синтаксическая проверка всех изменённых JS/MJS и `git diff --check` пройдены.
- Автоматически проверены все 12 подтверждённых цен, отсутствие вымышленной цены мастера, почасовая глажка, уникальность ID, цели внутренних ссылок/ARIA, наличие файлов, правильные контакты, автономность HTML и бюджет до 250 КБ.
- Удалены неподтверждённые длительности и состав работ из исходного JSON.
- Производственный `check:release` ожидаемо блокирует выпуск по понятным причинам (версия согласования и незавершённая правовая часть), а не падает на отсутствующем config.js.

## 2. Браузерная проверка

- Desktop, 768, 390 и 320 px. На проверенных мобильных ширинах нет горизонтального переполнения страницы; полоса фильтров прокручивается отдельно.
- Все четыре фильтра: 12 / 5 / 4 / 3 услуги. Все три быстрых перехода первого экрана выбирают соответствующую категорию.
- Все 12 карточек проверены на открытие и закрытие.
- Все пять вопросов FAQ открываются и закрываются клавишей Enter.
- Мобильное меню раскрывается; переход закрывает меню. Escape также закрывает его. Проверен вид раскрытого меню на 320 px.
- Обе фотографии открываются в диалоге. Кнопка закрытия и Escape работают. После закрытия возвращается фокус, разблокируется прокрутка.
- Окно «О сайте и обращениях» открывается и закрывается.
- Контактные ссылки проверены по адресатам: `tel:+79920070181`, `https://t.me/+79920070181`. Звонки и сообщения не отправлялись. Боты намеренно отключены и подписаны «скоро».
- При выключенном JS содержимое, 12 нативных details и 19 телефонных ссылок остаются в документе; неработающие JS-кнопки скрыты. Автоматический клик по details при отключённом JS упёрся в ограничение инструмента и не считается выполненным тестом.
- При `prefers-reduced-motion: reduce` плавная прокрутка отключается, а класс анимационных улучшений не добавляется.
- Ошибок и предупреждений в консоли страницы при проверке не обнаружено.

## 3. Публичная публикация

- Анонимный HTTPS-запрос вернул 200 и `Content-Type: text/html`.
- Загруженный файл полностью совпал с локальной сборкой; размер 180 999 байт (176,8 КиБ).
- В публичном браузере повторно проверены фильтр химчистки, открытие услуги, просмотр/закрытие фотографии, 320 px без горизонтального переполнения, загрузка обоих оригиналов 572 px.
- Внешних ресурсов для отрисовки страницы нет: CSS, JS, знак и фотографии встроены. Для открытия не требуется вход в облако. Облачный запрос выполнен без учётных данных.
