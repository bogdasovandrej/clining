Дата: 25.09.2026. [Страница для согласования](https://storage.yandexcloud.net/clining-preview-bogdasovandrej-20260920/preview.html?v=20260925-reviews).

## Сборка и содержание

- `npm run build`, `npm run check`, `node --check` изменённых скриптов, `git diff --check`.
- Проверка подтверждённых цен всех 12 услуг, почасовой глажки и отсутствия выдуманной цены мастера.
- Прайс: 12 обычных карточек, все цены видны сразу. Фильтры показывают 12 / 5 / 4 / 3 услуги.
- Нет раскрывающихся карточек услуг, фотогалереи, нумерации разделов «01 / ...», «02 / ...».
- Отзывы: три сокращённые цитаты из присланных скриншотов Авито. Указано, что на снимке было пять отзывов и общая оценка 4,2 из 5; не заявляется оценка 5,0.
- Проверены внутренние якоря, ссылки `tel:+79920070181` и `https://t.me/+79920070181`, неактивные боты, отсутствие форм и внешних ресурсов.

## В браузере

- Desktop и мобильные размеры 390/320 px. На 320 px карточки в один столбец, фильтры в две строки, горизонтального переполнения нет.
- Мобильное меню, фильтр «Химчистка» (четыре услуги), контакты и блок отзывов отображаются.
- FAQ и окно «О сайте и обращениях» открываются на локальной версии после правки.
- После загрузки публичный HTTPS-запрос вернул 200. Тело ответа побайтно совпало с локальной сборкой (35 927 байт). В публичном браузере подтверждены 12 карточек, 3 отзыва, отсутствие фото и нумерации разделов; фильтр «Другие услуги» показывает 3 услуги. Ошибок консоли нет.
