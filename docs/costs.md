# Оценка расходов

Актуально на 21.09.2026. Тарифы меняются, перед промышленным запуском расчёт нужно повторить.

## Демонстрационный макет

Планируется один HTML-файл размером около 0,36 МБ в стандартном Yandex Object Storage. Лимит бакета 1 ГБ — это ограничение, а не зарезервированный или заранее оплаченный объём.

Ожидаемая стоимость: **0 ₽/месяц**, пока суммарное потребление облака остаётся в бесплатных пределах Object Storage:

- первый 1 ГБ стандартного хранения в месяц;
- первые 10 000 операций записи и списка;
- первые 100 000 операций чтения;
- первые 100 ГБ исходящего трафика.

После бесплатного порога стандартное хранение стоит 2,376 ₽ за ГБ в месяц; чтение — 0,46 ₽ за 10 000 операций; исходящий трафик сверх 100 ГБ — по действующей шкале. Оплачивается фактическое потребление.

Источник: [тарифы Yandex Object Storage](https://yandex.cloud/ru/docs/storage/pricing).

## Рабочий сайт

Для небольшого локального сервиса предлагаем бессерверную схему: Object Storage для сайта, API Gateway, Cloud Functions и Serverless YDB для заявок. У API Gateway первые 100 000 запросов в месяц бесплатны, у Cloud Functions — первый 1 млн вызовов. YDB тарифицирует фактические запросы и объём данных с ежемесячным бесплатным пакетом. При малой нагрузке облачная часть может оставаться около 0 ₽, но это не гарантия: начисления зависят от трафика, ошибок, фотографий и числа обращений.

Источники: [API Gateway](https://yandex.cloud/ru/services/api-gateway), [Cloud Functions](https://yandex.cloud/ru/services/functions), [Serverless YDB](https://yandex.cloud/ru/docs/ydb/pricing/serverless).

Отдельно оплачиваются:

- домен — ежегодно по тарифу регистратора;
- при необходимости платный DNS, дополнительные фото, резервные копии и трафик сверх бесплатных порогов;
- SMS или другие внешние сервисы, если заказчица их выберет.

Перед подключением любого ресурса с заметной фиксированной платой требуется отдельное согласование. Виртуальную машину с постоянной почасовой оплатой для этого проекта не используем.
