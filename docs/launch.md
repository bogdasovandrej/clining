# Запуск naviteco.ru

Статус на 25.09.2026: домен показан свободным в WHOIS реестра .RU и в корзине Рег.ру за 169 ₽ на первый год. Домен ещё не оплачен и не зарегистрирован. Корзина очищена от автоматически предложенных подписки, второго домена, хостинга и конструктора. Цену продления сверить в аккаунте перед оплатой.

1. Владелец входит в Рег.ру, проверяет, что в корзине только `naviteco.ru`, регистрирует домен на своё имя и лично завершает оплату.
2. До открытия индексации Елена подтверждает право на публикацию отзывов, фактическую услугу озонирования, статус НПД и порядок обработки клиентских данных. Согласовать оператора персональных данных и уведомление РКН. Не выставлять `legalReviewApproved: true` лишь ради прохождения сборки.
3. Создать отдельный production-бакет `naviteco.ru` в Yandex Object Storage: имя бакета должно точно совпадать с доменом. Настроить хостинг `index.html`, DNS и бесплатный сертификат Let's Encrypt через Certificate Manager. Превью-бакет не переименовывать и не удалять.
4. Проверить `https://naviteco.ru/` с телефона, HTTP → HTTPS, контакты, меню, карточки услуг, 404, файл `robots.txt` и `sitemap.xml`.
5. После одобрения релиза выставить `preview: false`, `siteUrl: https://naviteco.ru/`, `legalReviewApproved: true`; собрать и запустить `npm run check` и `npm run check:release`, затем выложить `dist/`.
6. В Яндекс Вебмастере добавить именно `https://naviteco.ru/`, подтвердить владение через DNS TXT или HTML-файл, отправить sitemap и проверить индексирование. Добавлять демоссылку `storage.yandexcloud.net` в Вебмастер не нужно.

До шага 5 действующая демоверсия сохраняет `noindex` и `Disallow: /`; это намеренно. Покупка домена сама по себе не разрешает открывать сайт для поиска.

Источники: [домен и HTTPS в Object Storage](https://yandex.cloud/ru/docs/storage/operations/hosting/own-domain), [быстрый старт Яндекс Вебмастера](https://yandex.ru/support/webmaster/ru/service/quick-start), [проверка перед запуском](legal-review.md).
