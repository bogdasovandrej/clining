- [x] Бело-синий адаптивный сайт, мобильная кнопка звонка и фильтры услуг.
- [x] 12 услуг: исходный прайс, «Мастер на час» и глажка 500 ₽/час.
- [x] Единый каталог подтверждённых цен; неизвестная цена мастера не выдумана.
- [x] Рабочий синий знак, автономный HTML без внешних шрифтов и скриптов.
- [x] Публичная HTTPS-ссылка, открывающаяся с телефона; сайт не собирает ПДн через форму.
- [x] План, опросник, шаблон обратной связи и проектное решение по системе.

- [ ] Утвердить бренд, проверить имя/домен/товарные знаки, зарегистрировать домен на заказчицу.
- [ ] Финальная политика ПДн, отдельное согласие и проект уведомления РКН под фактического оператора и процессы.
- [ ] Российская транзакционная база, API создания и статуса заявки.
- [ ] Идемпотентный повтор, серверная валидация, ограничение частоты, CORS и таймауты.
- [ ] Авторизация мастера и минимальный список заявок с подтверждением/переносом/отменой.
- [ ] Одновременные уведомления Telegram и MAX после сохранения, повтор доставки, проверка адресатов.
- [ ] Согласованный канал ответа клиенту; напоминание только после подтверждения визита.
- [ ] Telegram/MAX, единицы расчёта и фотографии/кейсы при наличии разрешения. Телефон уже добавлен.

## Исходное ТЗ: дополнительные сценарии

Сохраняем требования, но перед реализацией подтверждаем их необходимость:

- [ ] Клиентский Telegram-бот: услуга, детали, заявка, подтверждение и напоминание.
- [ ] Клиентский MAX-бот с проверенным доступом; простой сценарий без тяжёлого календаря.
- [ ] Расширенный TG мастер-бот: график, блокнот, календарь.
- [ ] MAX мастер-бот: уведомления, список и действия по заявке.
- [ ] Оценка по фото внутри ботов с хранением и согласованным сроком удаления.
- [ ] Календарный планер и ICS-подписка, если нужны заказчице.
- [ ] Административная диагностика `/diag`, наблюдение за очередью и интеграциями.

Состояния заявки: новая → уточнение → согласована → выполнена. Отдельные исходы: отменена, отклонена. Желаемая дата в новой заявке не резервирует занятость мастера автоматически.
