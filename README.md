# НавитЭко

Первая версия сайта для согласования с заказчицей: [открыть с телефона](https://storage.yandexcloud.net/clining-preview-bogdasovandrej-20260920/preview.html?v=20260925).

На странице есть 12 услуг, подтверждённые стартовые цены, график 8:00–20:00, зона выезда и рабочий телефон. Для услуги «Мастер на час» цена ещё не получена; глажка стоит 500 ₽ за час. Запись согласовывается по телефону или в личном Telegram: клиент называет желаемую дату, затем специалист оценивает задачу и подтверждает время.

В этой версии нет сбора персональных данных через сайт. Ссылка Telegram ведёт на личный аккаунт по номеру телефона и зависит от его настроек приватности. Кнопки будущих Telegram- и MAX-ботов неактивны. Индексация страницы закрыта на этапе согласования.

## Локальная сборка

```powershell
npm run build
npm run check
npm run preview
```

Нужен Node.js 22; установка пакетов не требуется. Публичный файл собирается в `review/preview.html` и `dist/preview.html`. Это один автономный HTML-файл со встроенными стилями и логотипом.

Исходный код: [bogdasovandrej/clining](https://github.com/bogdasovandrej/clining). Публикация пока ручная в Yandex Object Storage. [Схема хостинга](docs/hosting.md), [вопросы заказчице](docs/client-questionnaire.md), [план развития](docs/backlog.md).
