# Чисто рядом

Прототип сайта клининга и химчистки для Екатеринбурга. «Чисто рядом» — рабочее название. Каталог услуг хранится в `data/services.json`; из него генерируются страницы и базовые цены. Коэффициенты калькулятора пока предварительные и требуют согласования.

Репозиторий: [bogdasovandrej/clining](https://github.com/bogdasovandrej/clining). Публичный хостинг выбран в **Yandex Cloud, регион Россия**. GitHub используется для исходников и сборки; GitHub Pages не используется.

## Запуск

```powershell
npm run build
npm run check
```

Нужен Node.js 22. Установка npm-зависимостей не требуется. Результат собирается в `dist/`. Для локального просмотра можно выполнить `python -m http.server 4173 --bind 127.0.0.1 --directory dist` и открыть `http://localhost:4173/`.

## Текущее состояние

Есть главная, девять страниц услуг, калькулятор, интерфейс записи, SEO-файлы и черновик политики ПДн. Контакты и домен тестовые. Онлайн-запись отключена: backend, база, боты, планер и напоминания ещё не реализованы. Формула калькулятора не является утверждённым прайсом. Lighthouse и работа на физическом Android-устройстве ещё требуют проверки.

## Сборка и публикация

GitHub Actions проверяет исходники и сборку при push и pull request в `main`. Сборка сохраняется как артефакт, без публикации сайта.

Отдельный workflow `Deploy to Yandex Object Storage` запускается вручную после настройки облака. Он отключён до установки `YC_DEPLOY_ENABLED=true` и проверяет отсутствие известных заглушек перед загрузкой. Подробности: [docs/hosting.md](docs/hosting.md).

До публикации замените тестовые контакты и домен, заполните политику ПДн, настройте публичный API в `assets/config.js` и реализуйте российский контур по [functions/README.md](functions/README.md).

В репозитории намеренно нет токенов, ключей и реальных персональных данных.
