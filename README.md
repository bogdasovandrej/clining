# НавитЭко

Версия сайта для согласования с заказчицей: [открыть с телефона](https://storage.yandexcloud.net/clining-preview-bogdasovandrej-20260920/preview.html?v=20260925-reviews).

На опубликованной странице есть 12 услуг, отзывы из присланных скриншотов Авито, подтверждённые стартовые цены, график 8:00–20:00, зона выезда и рабочий телефон. Для услуги «Мастер на час» цена ещё не получена; глажка стоит 500 ₽ за час. Запись согласовывается по телефону или в личном Telegram: клиент называет желаемую дату, затем специалист оценивает задачу и подтверждает время.

В этой версии нет форм сбора данных, оплаты и аналитических счётчиков. Хостинг получает технические сведения о запросах; обработку переписки и данных клиентов нужно оформить отдельно. Ссылка Telegram ведёт на личный аккаунт по номеру телефона и зависит от настроек приватности. Кнопки будущих Telegram- и MAX-ботов неактивны. Индексация страницы закрыта на этапе согласования.

Обновлённая версия включает мобильное меню, фильтры и 12 обычных карточек с видимой ценой, FAQ и отдельный блок отзывов. Фотогалерея убрана после обратной связи: исходные скриншоты выглядели на странице плохо, а менять результат работы с помощью ИИ было бы нечестно. Анимации учитывают настройку уменьшения движения. Основное содержимое и контакты доступны без JavaScript.

[Предзапусковая правовая проверка](docs/legal-review.md): до коммерческого запуска остаются данные исполнителя, процессы обработки персональных данных и уточнение услуги озонирования. `npm run check:release` блокирует производственный деплой до их согласования; это не препятствует передаче ссылки для обсуждения дизайна.

## Локальная сборка

```powershell
npm run build
npm run check
npm run preview
```

Нужен Node.js 22; установка пакетов не требуется. Публичный файл собирается в `review/preview.html` и `dist/preview.html`. Это один автономный HTML-файл со встроенными стилями и логотипом.

Исходный код: [bogdasovandrej/clining](https://github.com/bogdasovandrej/clining). Публикация пока ручная в Yandex Object Storage. [Схема хостинга](docs/hosting.md), [вопросы заказчице](docs/client-questionnaire.md), [план развития](docs/backlog.md).
