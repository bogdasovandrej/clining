# НавитЭко · концепция 01

Прототип сайта клининга и химчистки для Екатеринбурга. «НавитЭко» — вариант заказчицы; точное написание, смысл и латиницу ещё нужно подтвердить. Стиль: белый, синий и светло-голубой; три варианта векторного знака. Каталог 10 услуг хранится в `data/services.json`; из него генерируются страницы и базовые цены. Калькулятор показывает стартовую стоимость и количество предметов без выдуманных доплат.

Репозиторий: [bogdasovandrej/clining](https://github.com/bogdasovandrej/clining). Публичный хостинг выбран в **Yandex Cloud, регион Россия**. GitHub используется для исходников и сборки; GitHub Pages не используется.

## Запуск

```powershell
npm run build
npm run check
npm run preview
```

Нужен Node.js 22. Установка npm-зависимостей не требуется. Результат собирается в `dist/`. `npm run preview` запускает локальный сервер по адресу `http://127.0.0.1:4173/` без кэширования.

Для отправки заказчице используйте `review/preview.html`: это один автономный файл со стилями, кодом, иллюстрацией, страницами услуг и подборкой логотипов внутри. Интернет ему не нужен. На телефоне файл нужно скачать и открыть в браузере; встроенный просмотрщик мессенджера может не выполнять JavaScript. Хостинговая копия также создаётся как `dist/preview.html`.

## Текущее состояние

Есть главная, 10 страниц услуг, страница концепции, демонстрационный калькулятор, интерфейс заявки и черновик политики ПДн. Поля контактов отключены; мессенджерные кнопки сообщают о демонстрационном режиме. Backend, база, боты и напоминания ещё не реализованы. Полноценный планер не обязателен для первого релиза — рекомендуем сначала учёт и ручное подтверждение заявок. Индексация макета запрещена через meta robots и robots.txt. Lighthouse и физический Android ещё не проверены.

## Сборка и публикация

GitHub Actions проверяет исходники и сборку при push и pull request в `main`. Сборка сохраняется как артефакт, без публикации сайта.

Отдельный workflow `Deploy to Yandex Object Storage` запускается вручную после настройки облака. Он отключён до установки `YC_DEPLOY_ENABLED=true` и проверяет отсутствие известных заглушек перед загрузкой. Подробности: [docs/hosting.md](docs/hosting.md).

Публиковать текущую версию можно только как обозначенный демонстрационный макет без сбора данных. Перед запуском для реальных клиентов замените контакты и домен, заполните политику ПДн, реализуйте API и российский контур по [functions/README.md](functions/README.md). Снятие `preview` само по себе не включает реальную запись.

В репозитории намеренно нет токенов, ключей и реальных персональных данных.
